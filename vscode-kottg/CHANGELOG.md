# Change Log

All notable changes to the Kottg VSCode extension will be documented in this file.

## [1.0.0] - 2025-11-14

### Added
- Initial release
- Syntax highlighting for .kg files
- 30+ code snippets for rapid development
- Auto-completion and bracket matching
- Comment support (line and block)
- Code folding
- VSCode tasks for compilation
- Debug configuration for compiler
- Language configuration with proper indentation
- Full TextMate grammar for Kottg syntax
- Support for all Kottg keywords and types
- Built-in variable highlighting (msg, block, tx, self)
- Precompiled function support
- Event and modifier highlighting

### Features
- Contract template snippets
- Function snippets (public, view, require)
- Statement snippets (if, loop, while, match)
- Validation snippets (assert, require, revert)
- Precompiled function snippets
- Full contract template with common patterns

### Tasks
- Build Kottg Compiler
- Compile Current Contract
- Compile with AST view
- Compile with Disassembly
- Compile with all options
- Compile all example contracts

### Configuration
- Auto file association for .kg files
- Proper tab and spacing configuration
- Exclude .bin files from search
- Go language server integration
